### NumPy vs Pandas

Pandas is built on top of NumPy, but each library serves a different purposes and has its own strengths. Pandas specializes in manipulating and analyzing structured data, whereas NumPy is optimized for fast, large-scale numerical computations. As a result, the two libraries are often used together, with the choice of library depending on the type of the data and the specific task.

## Series

A Series is a one-dimensional labeled data structure in Pandas that is widely used for data analysis. It stores a sequence of values and provides efficient access to data through an index.

A Series has the following features:
- **One-dimensional data structure**: Stores a sequence of values in a single dimension
- **Index**: Every element has an associated index. By default, the index consists of integers starting at 0, but custom index labels can also be defined.
- **Data types**: A Series typically stores values of a single data type, although it can also contain mixed data types when necessary.
- **Functionality**: Provides a wide range of built-in methods and attributes for statistical analysis, data filtering, arithmetic operations, and other data manipulation tasks.

### Difference Between Series and List

Series and Python lists are both one-dimensional data structures, but they serve different purposes. A Series is designed for data analysis and supports labeled indexing, statistical operations, filtering, and efficient handling of large datasets. In contrast, a Python list is a general-purpose data structure used to store ordered collections of items. While lists provide basic operations such as appending, removing, and sorting elements, they are not optimized for large-scale data analysis.

### Creating a Series

A Series can be created from a Python list or NumPy array. If no index is provided, Pandas automatically assigns a default integer index starting at 0. Alternatively, you can specify your own custom index labels to suit your application.

```python
import pandas as pd  
  
x = [10, 20, 30, 40, 50]  
y = pd.Series(x)  
  
print(y)
```
```
Outcome

0    10
1    20
2    30
3    40
4    50
dtype: int64
```

```python
import pandas as pd  
  
x = [10, 20, 30, 40, 50]  
y = ['a', 'b', 'c', 'd', 'e']  
z = pd.Series(x, index=y)  
print(z)
```
```
Outcome

dtype: int64
```

### Viewing Data

#### head()
The head() method displays the first n elements of a Series. If no argument is specified, it displays the first 5 elements by default.

#### tail()
The tail() method displays the last n elements of a Series. If no argument is specified, it displays the last 5 elements by default.

### Indexing and Slicing

A Series is one-dimensional data structure, and its data can be selected using `.iloc[]` and `.loc[]`.  The `.iloc[]` indexer selects data by integer position, whereas `.loc[]` selects data by index label.

The `.iloc[]` indexer selects data based on its integer position. It can be used to retrieve either a single element or a range of elements through slicing.

```python
import pandas as pd  
  
data = pd.Series([10, 20, 30, 40, 50, 60, 70])  
print(data.iloc[1])  
print(data.iloc[1:4])
```
```
Outcome
```

The `.loc[]` indexer selects data based on index labels.

```python
import pandas as pd  
  
data = pd.Series([10, 20, 30, 40, 50, 60, 70], index=['a', 'b', 'c', 'd', 'e', 'f', 'g'])  
print(data.loc['b'])
print(data.loc['b':'d'])
```

### Adding Data

Data can be added to a Series using either the .concat() function or assignment.
- .concat() combines two or more Series objects into a new Series.
- Assignment adds a new element by assigning a value to a new index label.

```python
import pandas as pd

s1 = pd.Series([10, 20], index=["A", "B"])
s2 = pd.Series([30], index=["C"])

# Using .concat()
s = pd.concat([s1, s2])

# Using assignment
s["D"] = 40
```

### Modifying Series Values

Values in a Series can be modified using assignment. You can update a single value by specifying its index label, or modify multiple values at once by selecting multiple indexes. In addition, conditional assignment allows you to update only the elements that satisfy a specified condition, making it an efficient way to modify data.

```python
import pandas as pd

s = pd.Series([10, 20, 30], index=["A", "B", "C"])

# Modify a single value
s["B"] = 25

# Modify multiple values
s[["A", "C"]] = [15, 35]

# Conditional assignment
s[s > 20] = 100
```

### Data Statistics and Summary

A Series provides built-in methods for calculating summary statistics, including the mean, sum, median, maximum, and minimum. These methods allow you to quickly summarize and analyze the data stored in a Series.

```python
import pandas as pd

s = pd.Series([10, 20, 30, 40, 50])
```

### Checking Unique Values

The value_counts() method returns the frequency of each unique value in a Series. By default, it returns counts, but when normalize=True is specified, it returns the relative proportion of each value insted.


### Data Filtering and Conditional Selection

Data in a Series can be filtered using Boolean indexing. A Boolean expression produces a Series of True and False values, and only the elements corresponding to True are returned.

Multiple conditions can also be combined using the & (AND) and | (OR) operators to perform more complex filtering.

```python
import pandas as pd

s = pd.Series([10, 20, 30, 40, 50])

# Single condition
single = s[s > 30]

# Multiple conditions
multiple = s[(s > 20) & (s < 50)]
```

### Sorting Data

The sort_values() method sorts a Series by its values in ascending or descending order. By default, values are sorted in ascending order. To sort them in descending order, set ascending=False.

The sort_index() method sorts a Series by its index labels in ascending or descending order.

```python
import pandas as pd

s = pd.Series([30, 10, 20], index=["c", "a", "b"])

valueAscending = s.sort_values()                   # Sort by values
valueDescending = s.sort_values(ascending=False)   # Descending order
indexAscending = s.sort_index()                    # Sort by index labels
indexDescending = s.sort_index(ascending=False)    # Descending index order
```

### Data Grouping and Aggregation

In a Series, the groupby() method groups data according to a specified criterion and summarizes the data applying various aggregation functions to each group.

The groupby() method groups data based on a specified criterion. It is useful for grouping data that belongs to the same category and then performing aggregation operations such as calculating the mean, sum and count for each group.

The agg() method allows multiple aggregation functions to be applied.

```python
import pandas as pd  
  
s = pd.Series([10, 20, 30, 10, 20, 30], index=['a', 'b', 'a', 'b', 'a', 'b'])  
  
# group by index and return sum  
x = s.groupby(level = 0).sum()  
  
# group by index and return sum, mean, and count  
y = s.groupby(level = 0).agg(['sum', 'mean', 'count'])
```

## DataFrame

A DataFrame is a two-dimensional labeled data structure provided by Pandas for storing and manipulating tabular data.

Each column in a DataFrame is represented as a Series, allowing different columns to store different data types.

- **Two-dimensional data structure**: Organizes data into rows and columns, where rows represent records and columns represent variables or attributes.
- **Index and column labels**: By default, rows are assigned integer indexes starting at 0, and each column has a column label.
- **Multiple data types**: Each column can store a different data type.
- **Advanced data manipulation**: Supports powerful operations such as filtering, grouping, aggregation, sorting, and other data analysis tasks.

### Creating a DataFrame

A DataFrame can be created in several ways. The most common approach is to create it from a Python list, where you can specify the column labels. A DataFrame can also be created from a dictionary, in which the keys represent column labels and the values represent the data for each column. In addition, a NumPy array can be used to create a DataFrame.

```python
import pandas as pd
import numpy as np

# From a list
df1 = pd.DataFrame(
    [[1, "Alice"], [2, "Bob"]],
    columns=["ID", "Name"]
)

# From a dictionary
df2 = pd.DataFrame({
    "ID": [1, 2],
    "Name": ["Alice", "Bob"]
})

# From a NumPy array
arr = np.array([[1, "Alice"], [2, "Bob"]])
df3 = pd.DataFrame(arr, columns=["ID", "Name"])
```

### Viewing Data

### Adding Data

Data can be added to a DataFrame by creating new columns or updating existing ones. The two most common approaches are the assign() method and column assignment.

The assign() method returns a new DataFrame with one or more added or modified columns. The original DataFrame remains unchanged.

Column assignment uses the syntax `DataFrame["column_name"] = value` to create a new column or update an existing one. Unlike assign(), this method modifies the original DataFrame directly.

```python
import pandas as pd

df = pd.DataFrame({
    "Name": ["Alice", "Bob"],
    "Score": [90, 85]
})

# Using assign()
new_df = df.assign(Passed=[True, True])

# Using column assignment
df["Passed"] = [True, True]
```

### Modifying DataFrame Values

Values in a DataFrame can be updated by specifying the row and column to modify. You can update a single value or multiple values at the same time.

`.loc[]` modifies values using row and column labels, while `.iloc[]` modifies values using the integer positions of rows and columns.

To update multiple values simultaneously, select multiple rows or columns using slicing or a list of labels (or positions), and then assign the new values.

```python
import pandas as pd

df = pd.DataFrame({
    "Name": ["Alice", "Bob", "Charlie"],
    "Score": [90, 85, 88]
}, index=["A", "B", "C"])

# Modify a single value using .loc
df.loc["B", "Score"] = 95

# Modify a single value using .iloc
df.iloc[2, 1] = 100

# Modify multiple values
df.loc[["A", "C"], "Score"] = [92, 98]
```

A DataFrame also supports conditional assignment, allowing you to update values that satisfy specific conditions. Boolean indexing can be used to select rows based on one or more conditions, and the values in selected columns can then be modified. Multiple conditions can be combined using the & (AND) and | (OR) operators.

```python
import pandas as pd

df = pd.DataFrame({
    "Name": ["Alice", "Bob", "Charlie"],
    "Score": [90, 75, 85]
})

# Update values that satisfy a condition
df.loc[df["Score"] < 80, "Score"] = 80

# Multiple conditions
df.loc[(df["Score"] >= 80) & (df["Score"] < 90), "Score"] = 90
```

### Merging and Combining Data

#### Basic Column-Based Merge

The merge() method combines two DataFrames using one or more common columns as the merge key. The on parameter specifies the column used to match rows, while the how parameter determines the type of merge to perform, such as inner, outer, left, or right.

how parameter
- inner: Returns only matching rows.
- outer: Returns all rows from both DataFrame.
- left: Returns all rows from the left DataFrame.
- right: Returns all rows from the right DataFrame.

```python
import pandas as pd

df1 = pd.DataFrame({
    "ID": [1, 2, 3],
    "Name": ["Alice", "Bob", "Charlie"]
})

df2 = pd.DataFrame({
    "ID": [1, 2, 4],
    "Score": [90, 85, 95]
})

# Merge on the "ID" column
result = pd.merge(df1, df2, on="ID", how="inner")

print(result)
```
```
Outcome

   ID   Name  Score
0   1  Alice     90
1   2    Bob     85
```

#### Row-wise and Column-wise Merge

The concat() method combines two or more DataFrame along a specified axis. By setting the axis parameter, you can concatenate DataFrames row-wise(axis=0) or column-wise(axis=1).

```python
import panda as pd

df1 = pd.DataFrame({"A": [1, 2], "B": [3, 4]})
df2 = pd.DataFrame({"A": [5, 6], "B": [7, 8]})

# Row-wise concatenation (default)
row_result = pd.concat([df1, df2], axis=0)

# Column-wis concatenation
column_result = pd.concat([df1, df2], axis=1)
```

#### Combining a DataFrame and a Series

A Series can be added to a DataFrame as a new column using the syntax `DataFrame["new_column] = Series`. When the Series is assigned, Pandas automatically aligns the data by index. If an index in the Series does not match a row index in the DataFrame, the corresponding value is filled with NaN.

```python
import pandas as pd

df = pd.DataFrame({
    "Name": ["Alice", "Bob", "Charlie"]
}, index=[0, 1, 2])
scores = pd.Series([90, 85, 88], index=[0, 1, 2])

# Add the Series as a new column
df["Score"] = scores
```

### Sorting Data

The sort_values() method sorts a DataFrame by one or more specified columns. The by parameter specifies the column or columns used as the sorting keys. By default, the data is sorted in ascending order, but you can sort in descending order by setting ascending=False.

```python
import pandas as pd

df = pd.DataFrame({
    "Name": ["Alice", "Bob", "Charlie"],
    "Age": [25, 30, 25],
    "Score": [90, 85, 95]
})

# Sort by a single column
print(df.sort_values(by="Age"))

# Sort by multiple columns
print(df.sort_values(by=["Age", "Score"]))

# Sort in descending order
print(df.sort_values(by="Score", ascending=False))
```

### Data Grouping and Aggregation

The groupby() method groups a DataFrame by one or more columns. After grouping data, you can apply aggregation functions to each group to generate summary statistics, such as the mean, sum, count, minimum, and maximum.

```python
import pandas as pd

df = pd.DataFrame({
    "Department": ["Sales", "Sales", "IT", "IT"],
    "Salary": [3000, 3500, 4000, 4500]
})

# Group by a column
print(df.groupby("Department").mean())

# Apply multiple aggregation functions
print(df.groupby("Department").agg(["mean", "sum", "count"]))
```
